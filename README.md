# Full Stack Homework  # BE1-1 (robot.js)

## รายละเอียดการบ้าน
โปรแกรมนี้พัฒนาด้วย Node.js เพื่ออ่านข้อมูลจากไฟล์ข้อความ 4 ไฟล์ ได้แก่ `head.txt`, `body.txt`, `leg.txt` และ `feet.txt` จากนั้นนำข้อความมาต่อกันและสร้างไฟล์ใหม่ชื่อ `robot.txt`

## คำสั่งที่ใช้
- `fs.readFile()` อ่านข้อความจากไฟล์ต้นฉบับทั้ง 4 ไฟล์
- `fs.writeFile()` เขียนข้อความที่รวมกันลงในไฟล์ `robot.txt`
- `async/await` ควบคุมลำดับการอ่านและเขียนไฟล์
- `try...catch` จัดการข้อผิดพลาดที่อาจเกิดขึ้น

## วิธีรันโปรแกรม
1. ติดตั้ง Node.js
2. ดาวน์โหลดหรือ Clone Repository นี้
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์
4. ติดตั้ง Express ด้วยคำสั่ง `npm install`
5. รันโปรแกรมด้วยคำสั่ง `node robot.js`
